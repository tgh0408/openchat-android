# 本地签名配置

此目录只提交本说明，不提交密钥库、密码文件或其副本。2026-11-17 用户要求清空本机原签名文件，但自动审批阻止了删除操作；原文件仍留在本机，并由 Git 忽略规则排除。仓库中的此目录仅包含说明文档。

当前 [构建配置](../app/build.gradle.kts) 的 Debug 和 Release 共用发布签名，打包前须自行配置：

| 配置项 | 来源 |
| --- | --- |
| 密钥库 | 本机 `openchat-signing/openchat-release.jks` |
| 密钥别名 | `openchat` |
| 密钥库密码 | 环境变量 `OPENCHAT_STORE_PASSWORD`；未设置时读取本机 `openchat-signing/password.txt` |
| 密钥密码 | 环境变量 `OPENCHAT_KEY_PASSWORD`；未设置时沿用密钥库密码 |

密码文件仅去除末尾换行；不要在文件或环境变量值中添加引号。不要把实际密码写进 Gradle、文档或命令示例。仓库忽略本目录除 README 外的全部文件，不要使用 `git add -f` 提交密钥或密码。

克隆后尚不能直接生成当前配置要求的签名包，需要从可信的独立保管位置取得对应密钥。替换为新密钥会改变签名，不能假定可覆盖安装既有签名的应用。现有构建脚本不会自动生成密钥，也不会自动退回默认 Debug 签名。

应用登录账号、密码、Token、数据库密码和用户数据库同样不得提交。`local.properties`、IDE 设置、构建产物与本机缓存由仓库忽略规则排除。
