## 后续维护

新增或调整功能时，直接更新分模块说明和路线的验收条件，不再新增重复专题或一次性排查报告。需求被替代时明确写出新规则，不把相互矛盾的历史描述并列为当前要求。仓库开发约束另见 [编码规范](CLAUDE.md)。

跨端应对齐服务端协议、消息身份、数据含义、授权与状态转换；Android 的 Activity、前台服务、系统悬浮、APK 安装等需另做 iOS 适配。仅有同名表、依赖或按钮，不代表功能完整可用。
