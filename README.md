# OpenChat Android

OpenChat Android 是使用 Kotlin 和 Jetpack Compose 开发的原生即时通信客户端，面向个人聊天、群组交流和实时音视频通话。应用以“会话、通讯录、我”为主要入口，与 OpenChat PC 端共用业务服务端，并对齐消息、好友关系、群管理及通话协议。

本仓库包含 Android 客户端源码、构建配置和项目说明。后续 iOS 客户端可依据分模块说明与实现路线，复用服务端契约并完成对应的平台适配。

## 主要功能

- **账号与会话：** 配置服务器、账号密码登录、会话恢复校验、切换账号和退出登录。
- **即时聊天：** 单聊与群聊、历史消息分页、文本和图片发送、SSE 实时接收与刷新、发送状态及实际已读同步。
- **通讯录与群管理：** 好友搜索、申请与接受、用户资料、黑名单及删除好友，以及群成员管理、群名公告、置顶和免打扰。
- **文件与媒体：** 相册选择、拍照发送、文件和视频分片上传、断点下载、本地视频播放、按需转码及画中画。
- **音视频通话：** 单聊语音与视频、前台来电、P2P 优先及 SFU 中转、通话小窗、已接听单聊恢复，以及群语音和可选视频。
- **本地保护与设置：** 认证信息与聊天数据库加密、服务器和账号数据隔离、主题与字号设置、Android 应用更新。

以上为当前源码已接入的能力，具体入口限制和验证状态见分模块说明。注册、短信登录、系统推送与后台来电唤醒、语音消息录制发送、支付和消息端到端加密尚未接入。

## 技术栈

| 领域 | 实现 |
| --- | --- |
| 原生界面 | Kotlin、Jetpack Compose、Material 3 |
| 网络与实时事件 | OkHttp、SSE、Kotlin Serialization |
| 本地存储 | Room、SQLCipher、DataStore、Android Keystore |
| 音视频通话 | WebRTC、LiveKit |
| 视频播放与转码 | Media3、FFmpeg Kit |
| 工程组织 | Gradle 单 `app` 模块，按登录、聊天、通讯录、个人设置及公共能力划分目录 |

具体版本以 [依赖配置](gradle/libs.versions.toml) 和 [应用构建配置](app/build.gradle.kts) 为准。签名密钥、密码和本机配置不随项目提交，打包前需按下方签名说明配置。
